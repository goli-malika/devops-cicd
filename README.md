# AWS DevOps & CI/CD

## Module Overview
Learning Git, GitHub, Version Control, Continuous Integration, and Continuous Deployment.

## Learning Objectives
- Understand Git and GitHub
- Learn Version Control
- Understand CI and CD
- Explore AWS DevOps services
- Create a basic CI/CD pipeline
- Document the deployment workflow

## Tools and Technologies
- Git
- GitHub
- GitHub Actions
- AWS DevOps concepts

## Project
Build a basic CI/CD pipeline to automatically test a simple application when code is pushed to GitHub.
